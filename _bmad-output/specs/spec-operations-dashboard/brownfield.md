## Workshop and reconciliation facts

Normal guarded transitions are `to_prepare → being_prepared → needs_recheck → ready_for_pickup → in_rental → returned → prepare_for_storage → completed`. M1 completion enters needs_recheck; M2 requires designated checks, current add-on confirmation and attestation rules. Configuration failures block preparation. Cancellation and reassignment preserve history; checklist snapshots freeze after preparation begins. `needs_recheck` alone does not prove a changed allocation: it is also the ordinary post-M1 stage.

`src/lib/booqable/parse-source-snapshot.ts` traverses stock-item plannings for line assignments. It filters product tags beginning `workshop-` and excludes `-bundle` tags; invalid/missing/multiple tag configuration can still create a task with a configuration warning. Therefore a task, allocated item or `relevant` line is not independently proven to be a bike. If the sole matching tag is `workshop-partner-bike` and no stock planning exists, quantity produces synthetic `partner:<line-id>:<unit>` and `partner-sip:<line-id>:<unit>` identities (null quantity currently defaults to one). Keep that identity convention; do not use it as physical cross-order identity.

`src/app/api/webhooks/booqable/route.ts` validates a configured secret, classifies the event and uses the ID to fetch authoritative source data. `reconcile-order.ts` acquires/renews a fenced lease, fetches, parses and invokes transactional `booqable_apply_source_snapshot_v1`. Do not treat webhook bodies as snapshots or bypass that transaction. The current whole-order fulfillment policy only advances ready→in-rental with unambiguous positive uniform started evidence, and in-rental→returned on final stopped evidence. Mixed/unknown states do not advance all bikes; no backward transition or missed-stage catch-up is allowed. Existing source notices include mixed, unknown, not-ready, missed-pickup, reversal and local-ahead. Dashboard reads and warnings cannot trigger transitions; explicit reused sync retains existing effects.
